# 오늘도 정상영업 — 첫 버전 기획

사용자가 선택한 방향: 밤마다 바뀌는 편의점, 가벼운 공포, 친구와 협동.

## 핵심 흐름
주문 받기 → 상품 찾기와 전달 → 이상 현상 발견 → 협동 해결 → 영업 재개.

## 첫 버전 초안
- 우선 2인 협동으로 검증하고 이후 최대 4인을 검토한다.
- 편의점 하나: 계산대, 진열대, 작은 창고.
- 근무 시간 약 5분, 상품 3종.
- 이상 현상: 상품 위치 변화, 빈 통로 호출벨, 협동 정전.
- 성공 조건: 주문 5건, 정전 해결, 근무 종료를 모두 충족.
- 실패 조건: 가게 불안도 최대. 개인 탈락 없이 팀 결과 후 재도전.
- 정전 해결: 한 명은 차단기를 조작하고 다른 한 명은 매장 표시등 순서를 전달.
- 음성 채팅 없이도 협동할 수 있는 위치 표시/신호 제공.
- 초기에는 사건 순서와 상품 위치로 매번 다른 느낌을 만든다.

## 후속 범위
저장·성장·상점·복잡한 추격·여러 맵은 첫 플레이 흐름 검증 후 결정한다.

## 완료 기준
두 플레이어가 주문 처리, 정전 해결, 성공/실패, 재시작을 실제로 수행한다.
동일 주문 동시 완료 요청과 플레이어 이탈에서 진행과 보상이 꼬이지 않아야 한다.

아직 게임 구현이나 Studio 실행 검증은 완료되지 않았다.
