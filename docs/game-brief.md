# 오늘도 정상영업 — 단독 매장 운영 기획

갱신: 2026-11-01 / NightShift-PM / `release_pm_plan`.
최상위 요구는 [release-target.md](design/release-target.md), 실행 범위와 검사표는 [PM 출시 계획](design/pm-release-plan.md), 외부 근거는 [벤치마크 기록](design/retention-benchmark.md)이다. 과거 2인 직원·16인 공동매장·공동 소유 기획은 폐기한다. 옛 문서의 팀 예산·직원 권한·두 사람 필수 정전 풀이·교대 종료 재고 폐기는 이번 요구로 승계하지 않는다.

## 플레이 약속과 목표

한국 편의점 거리에서 **1인 1매장, 최대 운영자 8명**이 각자 발주·물류·진열·판매·성장을 담당한다. 빈 매장 하나만 서버가 배정하며 9번째 접속자는 대기 또는 입장 제한한다. 매장 자리 번호는 세션 배치이고 개인 영구 소유지가 아니다. 친구 방문과 공동 사건은 가능하지만 방문자가 직원·구매자·창고 관리자가 되지는 않는다. 혼자서 공포 대응을 포함한 정상 영업을 결제·음성 없이 끝낼 수 있어야 한다.

완료 목표는 **2026-11-01 09:00 KST의 배포 직전 로컬 검증본**이다. 공개 게시·실제 상품 생성/판매·광고 송출은 포함하지 않는다. 이 문서 갱신은 구현·Studio 통과 증거가 아니다.

## 핵심 흐름

빈 매장 배정·개인 프로필 복원 → 자기 사무실 PC에서 공용 도매 재고 확인·발주 → 트럭 도착 → 직접 하역·자기 창고 보관 → 직접 진열 → NPC의 상품 선택·계산·구매 → 실제 재고 차감과 돈·실적 증가 → 게임머니 업그레이드·다음 발주.

- **PC 주문·공유재고:** 같은 서버의 공급처 재고를 8개 매장이 경쟁한다. 구매 후 상품과 돈은 소유자별로 관리하며 다른 사람과 합치지 않는다. 마지막 한 개 동시 주문은 한 건만 승인하고 실패자의 돈은 보존한다. 가격·재입고·실패 이유는 PC에서 확인한다. 희귀품이나 결제가 없어도 기본품으로 영업을 계속한다.
- **트럭·창고·직접 진열:** 배송 예약과 실물 상품을 연결한다. 하역→창고→선반을 플레이어가 운반하며 창고가 자동 판매·자동 진열을 대신하지 않는다. 재고는 주문/트럭/창고/운반/선반/판매/회수 중 한 상태에만 존재한다.
- **NPC 판매:** 일반 손님은 무작위로 방문해 실제 진열품을 선택하고 계산대를 거쳐 구매한다. 서버가 판매를 확정해야 돈이 증가한다. 희귀 부자손님은 낮은 확률로 더 많이 구매하지만 없는 물건을 만들지 않는다. 무료 확률이며 유료 등장권·확률 상승은 없다.
- **교통·보행:** 차량은 차도, 보행 NPC는 인도와 횡단보도로 이동한다. 차량·보행자 모두 신호를 지킨다. 플레이어의 차도 충돌은 들고 있던 상품만 기존 드롭/회수 규약에 넘긴다. 지갑·저장 자산을 삭제하지 않는다. 드롭으로 재고가 복제되거나 타인의 영구 자산으로 넘어가면 실패다.
- **저장·업그레이드:** 돈·레벨·무료 업그레이드·창고/진열 상품·도감/실적을 UserId 기준으로 복원한다. 재접속 시 새 빈 매장에 배치하고 현재 DisplayName/닉네임을 간판에 표시한다. 저장 실패를 신규 프로필로 덮지 않는다. 교대 종료·자리 변경으로 개인 소유 재고를 폐기하지 않는다.
- **가벼운 공포:** 첫 판매 뒤 짧은 정전 한 종류를 최소 범위로 둔다. 혼자 표시등을 확인하고 차단기를 조작해 복구한다. 순서 확인을 위해 다른 사람·음성·결제는 필요하지 않다. 실패해도 자산 소멸 없이 무료 재시도·영업 복귀가 가능하다.
- **방문·경보:** 남의 PC 구매·창고 입출고·업그레이드는 거절한다. 도난 시도/경보는 별도 서버 판정이며 영구 자산 강탈 경로를 허용하지 않는다. 실제 운반 중 경보를 허용하더라도 원소유권을 유지하고 회수하며, 남의 상품 판매·자기 프로필 편입은 차단한다. 기존 확보 후 소유권 이전은 새 계약 검토 전 비활성 대상이다.

## 도감 밖의 다음 영업 동기

아래 2개를 일정 내 최소 제안으로 독립 검토에 넘긴다. 수치·재미·유지율 효과는 모두 미검증 가설이며 아직 채택·실행 완료가 아니다.

1. **짧은 서버 영업대회:** 5분 동안 매출액 대신 판매 품목 다양성·발주 목표 달성·자기 물류 완결을 각각 평가한다. 기본 도구와 기본품만 점수에 인정하고 부자손님 추가 구매·영구 업그레이드·유료 외형은 우위를 주지 않는다. 늦게 온 사람은 다음 회차나 개인 연습을 선택한다. 참가비·연속 접속 보상·영구 순위 능력치는 없다.
2. **변동 수요·발주 목표:** 영업 전 미리 보이는 기본품 2종의 소량 판매 목표를 제안한다. 같은 서버에는 같은 목표가 적용되며 다음 회차에 선택을 바꾼다. 목표를 놓쳐도 손실·해금 차단이 없고 언제든 일반 영업을 계속한다. 공유재고 접근성이 확보되지 않으면 해당 목표를 안전한 대체품으로 바꾼다.

매장 전문화·단골 관계는 최소 두 기능의 이해도·반복 플레이를 관찰한 뒤 확장한다. 초기에는 단골의 선호 표시와 무능력치 간판 테마 정도를 후보로 두며 추가 저장 필드를 서둘러 늘리지 않는다.

## 한국 편의점 공간과 광고 준비

앞문·계산대·진열·사무실 PC·창고·뒤 하역장을 한 사람이 찾을 수 있게 표지와 통로를 연결한다. 광고는 거리 2면+옥상 4면=외부 6면, 도로 양쪽 고르게 배치한다. 내부 LCD·트럭 면은 외부 6면과 별도 집계한다. 직접 제작한 자체 안내를 기본으로 사용하며 입구·신호·하역·PC 표지를 가리지 않는다. 번쩍임·자동 영상·강제 시청·실제 협찬으로 오인할 이미지를 넣지 않는다. 상세 공간/광고 검토는 [기존 독립 검토](design/store-design-review.md)를 참고하되 송출 승인으로 간주하지 않는다.

수익화 후보는 능력치 없는 외형·간판 장식과 승인 후 광고다. 모든 정상 진행·성장·대회는 무료로 완결한다. 유료 랜덤 보상·승리 판매·실패 직후 구매 유도는 제외한다. 공식 Codex 구독 외 유료 API·유료 에셋·구매·Roblox 게시는 실행하지 않는다.

## 완료 판정

[PM 계획의 T01~T15](design/pm-release-plan.md)로 기능별 실제 결과와 미검증을 구분한다. 최소 2명 서로 다른 매장 배정, 공유 마지막 재고 경쟁, PC→배송→창고→진열→NPC 구매, 권한 거절·경보, 충돌 드롭·신호, 무료 정전 복구, 재접속 복원과 저장 실패 보호를 확인한다. 모바일 에뮬레이션과 실제 터치, 모의 저장과 실제 클라우드 저장, 2명 테스트와 8인 부하는 서로 다른 증거다. 증거가 없으면 미완료/미검증으로 남기며 기한에 맞춰 성공으로 바꾸지 않는다.
