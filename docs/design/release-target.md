# 11월 1일 오전 9시 개발 목표

- 완료 기한: 2026-11-01 09:00 Asia/Seoul. 목표는 배포 직전 검증본. Roblox 공개 게시·실제 상품 판매를 실행하지 않는다.
- 최신 사용자 결정: **1인 1매장, 직원 참가와 공동 소유 제거.** 8개 매장 기준 동시 운영자 8명. 자동 배정은 비어 있는 매장 하나에만, 1명에게 2개 매장 금지. 재접속 개인 프로필은 유지하되 서버 간 매장 자리 번호를 영구 소유권으로 취급하지 않는다.
- 각 플레이어의 주문·재고·매장 운영·레벨은 해당 매장 소유자 기준. 다른 매장 방문·명시적 도난/경보·공동 이벤트는 가능하지만 직원 권한을 주지 않는다. 남의 사무실 PC 구매와 창고 보관/출고는 거절한다. 9번째 플레이어에게 중복 매장을 주지 않는다.
- 기존 직원 선택/참가/지원 UI, 팀 공유 재고·보상·자동 인력 분산 로직을 점검한다. 매장 인원 기반 주문 증가/감소 대신 소유자 단위 조정. 1인으로 정상 영업과 공포 이벤트를 무료 완결할 수 있어야 한다.
- 옥상 광고판 4개 추가: 도로를 향한 양쪽 매장에 고르게 배치. 기존 거리 2개 + 옥상 4개 = 외부 6개 목표. 내부 광고면은 별도 집계. 직접 제작, 시야/입구/하역/사무실 표지 간섭 금지, 번쩍임/자동 영상/강제 시청 금지. 공급 계약 없는 실제 협찬 이미지를 꾸며내지 않는다.
- 우선순위: 재고 보존·권한·소유권·프로필 손상 방지 → 이동 중 바닥 안정 → PC 주문/트럭/창고/직접 진열/판매 → 한국 편의점 동선/광고 가시성 → 독립 검토/실제 플레이/저장.
- 배포 확인 항목: 실제 2명 이상 서로 다른 매장 배정·같은 재고 마지막 1개 경쟁·도난 경보·퇴장/재접속·모바일 터치·일반 보행 복귀 재현. 8인 부하/클라우드 영속 저장/실제 음성/광고 공급은 실제 수행 증거가 없으면 미검증.
- 재미·재방문·광고 수익 개선은 실측 전 가설. 오전 9시에 검증 결과·알려진 문제·남은 출시 조건을 분리해 보고한다.

## 추가 확정 요구 (00:30 KST까지)

- 진열한 실제 재고를 NPC가 선택→계산→구매해야 돈이 쌓인다. 일반 NPC 무작위 방문, 낮은 확률의 부자 NPC는 더 많은 재고를 구매. 서버 권한으로 재고·매출 보존, 품절/도난/주인 이탈 경합 검사. 유료 확률/랜덤상품과 연결하지 않는다.
- 차도 차량 운행, 차량 충돌 시 들고 있던 상품만 기존 운반/드롭 규약으로 떨어뜨린다. 개인 지갑이나 영구 저장자산 삭제 금지. 신호등, 횡단보도, 보행자는 인도와 횡단보도로만 이동하며 보행 신호 준수. 차량도 정지 신호 준수.
- 간판은 플레이어 DisplayName/닉네임. 돈·레벨·업그레이드·창고 및 진열 상품·도감/실적을 개인 프로필에 저장하고 재접속한 빈 매장에 복원. 저장 실패를 신규 데이터로 덮지 않음, 중복 복원/상품 복제 방지.
- 돈 벌기·도감만으로 끝내지 않는다. PM이 다른 게임의 공식 설명을 벤치마킹하여 상점 간 경쟁, 변화하는 목표, 재방문 동기를 설계. 짧은 공정 영업대회·매장 전문화·변동 수요/발주 목표 중 실제 재미와 일정에 맞는 작은 조합을 독립 검토 후 채택. 접속 스트릭 강요/영구 자산 약탈/유료 승리 방지.
- PM 전담 워커를 상시 역할로 두고 범위·의존성·우선순위·완료 증거·기한을 관리. 작업을 실제 모델 호출한 뒤 지도에 실행 상태 표시. PM 후보 제안은 실행/완료가 아니다.
