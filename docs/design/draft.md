- 작성: NightShift-Planner / 2026-10-31 / 독립 검토 전.
- 근거: 프로젝트 AGENTS.md, docs/planning-brief.md, docs/game-brief.md를 읽었다.
- 이번 산출물은 설계 초안이며 구현·Studio 테스트·에셋 반입을 수행하지 않았다.
- 파일의 후속 개발 승인과 별개로, 이번 참가자 요청에 따라 초안 작성까지만 수행한다.
- 아래 시간·횟수·목표·가격은 모두 검증 전 설계 가설이다. 재미·이탈·수익 실측은 없다.

## 1. 핵심 경험과 작은 범위
- 한 줄 경험: 친구와 편의점을 운영하다가 바뀐 진열과 정전을 함께 수습한다.
- 재미 가설 H1: 서로 다른 정보를 짧게 전달하고 성공하는 순간이 협동 만족을 만든다.
- 재미 가설 H2: 익숙한 가게에서 동선과 사건 시점이 달라지면 두 번째 밤도 관찰하게 된다.
- 재미 가설 H3: 실패 원인과 재도전 방법이 보이면 낮은 공포가 불쾌함보다 긴장으로 남는다.
- 첫 버전은 2인, 편의점 1개, 계산대·진열대 3개·작은 창고·차단기만 둔다.
- 상품은 물·빵·우유 3종이며 고정 이름과 서로 다른 도형 표지를 함께 쓴다.
- 근무는 진행 시간 300초, 필수 주문 5건, 필수 정전 1회로 구성한다.
- NPC 대화·추격·전투·개인 사망·인벤토리 확장·영구 성장·저장은 제외한다.
- 서버 간 매칭·자동 상점·실제 결제·4인 확장·추가 맵은 기본 재미 확인 뒤 검토한다.
- 첫 구현은 기본 Part와 직접 만든 UI로 모든 규칙을 표현할 수 있어야 한다.

## 2. 30초와 5분의 흐름
- 대기 중 두 사람이 준비를 누르면 무료 연습 안내를 보고 근무를 시작한다.
- 안내는 상품 집기·주문 번호·위치 신호·정전 신호를 실제 버튼으로 한 번씩 보여준다.
- 30초 루프 예: A가 주문 #03의 빵을 확인하고, B가 진열 위치를 찾아 계산대로 운반한다.
- A는 다른 상품을 찾는 대신 다음 이동을 도울 위치 신호를 찍거나 B와 역할을 바꾼다.
- 전달이 끝나면 공유 주문 수가 1 증가하고 다음 주문까지 짧게 주변 변화를 살핀다.
- 0~60초: 첫 주문과 신호 사용을 익힌다. 정전은 발생하지 않는다.
- 60~120초: 진열 이동 또는 빈 통로 호출벨을 만나 달라진 가게를 확인한다.
- 120~240초: 선택된 밤 일정에 따라 정전을 해결하고 주문을 이어간다.
- 240~300초: 남은 주문을 마치고 마감까지 영업 상태를 유지한다.
- 필수 주문을 일찍 끝내면 추가 주문 없이 청소 애니메이션 등 자유 행동만 허용한다.
- 모든 필수 목표 완료 시 두 사람 동의로 남은 시간을 건너뛰어 마감할 수 있다.
- 조기 마감은 남은 연출 사건을 취소하고 근무 종료 조건을 충족한다.

## 3. 주문과 역할 전환
- 활성 주문은 항상 1건이며 상품 한 종류 1개만 요구한다. 재고는 무제한이다.
- 첫 주문은 시작 10초 후, 이후 주문은 직전 주문 종료 8초 후에 생성한다.
- 주문 제한 시간은 45초이며 양쪽 화면에 번호·상품 이름·도형·남은 시간이 보인다.
- 주문을 놓치면 불안도 +15, 성공 수는 그대로이며 8초 후 대체 주문을 생성한다.
- 성공 5건에 도달하면 신규 주문을 중지한다. 만료 주문은 성공 건수에 포함하지 않는다.
- 누구나 집기·전달·계산을 할 수 있고 직업 선택이나 영구 역할 잠금은 없다.
- 손에는 상품 1개만 들며 내려놓기·반납은 무료이고 잘못 집은 상품에 벌점은 없다.
- 상품을 든 사람이 계산대에 전달하면 주문이 완료된다. 별도 계산 담당을 강요하지 않는다.
- 일반 주문은 혼자 처리할 수 있지만, 정상 2인 근무의 정전은 두 사람의 동시 참여가 필요하다.
- 정전 뒤에는 화면이 다음 밤에 역할을 바꿔 볼 것을 제안하되 강제하지 않는다.
- 사례: A가 앞서 운반했다면 정전 때 A는 표시판, B는 차단기로 이동해 다른 역할을 경험한다.
- 두 사람이 같은 상품을 운반해도 먼저 유효하게 전달된 한 개만 사용한다.
- 늦게 도착한 상품은 손에 남고 무료 반납할 수 있다. 다음 주문 자동 완료에 쓰이지 않는다.

## 4. 무음 협동과 조작
- 키보드는 상호작용 키, 터치는 화면 버튼으로 같은 행동을 수행한다.
- 기본 행동은 집기/전달, 내려놓기, 위치 신호, 정전 신호, 취소로 제한한다.
- 위치 신호는 계산대·각 진열대·표시판·차단기를 선택하면 목적지 표지와 짧은 문구를 보낸다.
- 신호는 5초 유지하며 발신자·대상·행동을 표시한다. 발신 간격은 최소 1초다.
- “여기 물”, “표시판 맡음”, “차단기 부탁” 등 고정 문구만으로 기본 진행이 가능하다.
- 정전 표시판에는 원·삼각·사각 중 3개 순서가 보이고, 신호 버튼으로 순서 전체를 공유한다.
- 차단기 담당은 화면에 공유된 도형 순서를 보고 같은 도형 버튼을 차례로 누른다.
- 공유는 표시판 담당이 직접 눌러야 하며 음성 입력이나 자유 채팅을 요구하지 않는다.
- 신호 수신 UI는 음량 0에서도 읽히며 색과 소리만으로 필수 정보를 전달하지 않는다.
- 모바일 화면에서 주문과 정전 신호가 상호작용 버튼을 가리지 않도록 고정 영역을 나눈다.
- 튜토리얼을 놓쳐도 목표 옆 도움말에서 현재 행동을 다시 볼 수 있다.

## 5. 정전 협동 규칙
- 표시판과 차단기는 한 사람이 동시에 조작할 수 없는 거리의 서로 다른 방에 둔다.
- 표시판 담당은 상호작용으로 연결을 켜고 해당 지점에 머문다. 계속 누르고 있을 필요는 없다.
- 연결 중 이동·취소하면 연결이 해제되고 UI가 이유를 표시한다.
- 차단기는 다른 참가자가 표시판을 연결한 동안에만 입력을 받는다.
- 한 참가자가 두 지점의 연결 소유자가 될 수 없다. 역할 교환은 연결 취소 후 가능하다.
- 신호가 공유되어도 표시판 연결이 끊기면 차단기 입력이 일시 중지된다.
- 입력 순서는 정전마다 고정하고 오입력 시 해당 입력 진행만 초기화한다.
- 오입력 자체에는 불안도 벌점이 없다. 정전 경과 시간에만 비용이 발생한다.
- 정전 중 주문 제한 시간과 신규 주문 대기는 멈추지만 근무 시간은 계속 흐른다.
- 정전 시작 후 15초·30초·45초에 각각 불안도 +10을 한 번만 적용한다.
- 45초 미해결이면 자동 복구하며 추가 벌점 없이 필수 정전을 ‘지원 복구’로 처리한다.
- 지원 복구도 마감 조건을 충족하되 결과에 협동 해결과 구분해 표시한다.
- 자동 복구 후 다음 밤에 무료 정전 연습을 제안한다. 상품이나 유료 해결책은 제시하지 않는다.
- 사례: A가 순서를 보내고 B가 입력하다 틀리면 A는 같은 신호를 다시 보내 재시도를 돕는다.
- 협동 해결은 즉시 영업을 재개하게 하며, 기다려 자동 복구하는 것보다 시간을 절약한다.
- 지원 복구는 교착 방지 장치다. 다수가 의도적으로 기다리는지는 별도 테스트로 확인한다.

## 6. 밤마다 체감되는 변화
- 무작위 사건을 무제한 조합하지 않고 아래 검증 가능한 일정 3개 중 하나를 선택한다.
- 밤 A: 진열 변경 60초 / 정전 120초 / 빈 통로 호출벨 210초.
- 밤 B: 빈 통로 호출벨 60초 / 진열 변경 100초 / 정전 180초.
- 밤 C: 진열 변경 80초 / 빈 통로 호출벨 140초 / 정전 200초.
- 같은 두 사람이 재시작하면 직전 일정과 다른 일정을 고른다. 선택 기록은 현재 세션만 유지한다.
- 상품 초기 배치는 3종의 6개 순열 중 하나이며 모든 상품에 접근 가능한 고정 진열대를 쓴다.
- 진열 변경은 상품 세 종류를 한 칸씩 순환시켜 빈 진열대나 사라진 상품을 만들지 않는다.
- 변경 예정 시각에 활성 주문이 있으면 그 주문 종료까지 미루고 다음 주문 생성 전에 적용한다.
- 변경은 최대 3초의 안내 후 실행한다. 들고 있는 상품과 계산대에 전달된 상품은 이동시키지 않는다.
- 정전과 변경 대기가 겹치면 정전을 먼저 처리하고 복구 뒤 변경한 다음 신규 주문을 낸다.
- 호출벨은 빈 통로 표지와 약한 소리만 내며 주문·벌점·필수 확인 행동을 만들지 않는다.
- 사건이 겹치면 호출벨을 생략한다. 정전과 진열 변경을 동시에 조작 과제로 내지 않는다.
- 정전 순서는 원·삼각·사각의 순열 중 하나이며 반복 도형이나 속임수 표시는 첫 버전에서 제외한다.
- 밤 안내는 “오늘은 진열이 바뀔 수 있습니다” 정도만 알리고 정확한 시각은 공개하지 않는다.
- 사례: 이전 밤의 물 위치로 뛰어갔는데 빵이 보이면 B가 물 위치 신호를 찍어 A의 동선을 바꾼다.
- 검증할 차이는 위치·사건 순서·정전 정보다. 조명 색만 바뀌는 것을 새로운 밤의 근거로 삼지 않는다.
- 모든 배치의 통로·표지판 시야·차단기 접근은 동일하게 보장하고 출입구를 잠그지 않는다.

## 7. 성공·실패와 불쾌함 줄이기
- 불안도는 0에서 시작하며 최대 100이다. 주문 만료와 정전 지연만 증가 원인이다.
- 70 이상이면 “주문을 놓치면 가게가 닫힙니다”와 원인별 증가 내역을 표시한다.
- 근무 종료에 성공 5건 이상·정전 처리 완료·불안도 100 미만이면 팀 성공이다.
- 불안도 100 도달 시 즉시 팀 실패이며, 300초 종료 시 미충족 목표가 있어도 팀 실패다.
- 동일 시점에는 정전·주문 유효 처리, 벌점 반영, 불안도 실패, 마감 성공/실패 순으로 판정한다.
- 서버 마감 시각 이전 또는 같은 시각에 접수한 유효 전달만 마지막 주문 판정에 포함한다.
- 한 사람만 죽거나 구경하는 상태는 없다. 성공·실패 화면은 함께 나타난다.
- 결과는 완료 주문·정전 처리 방식·놓친 주문·다음에 바꿀 행동 한 가지를 보여준다.
- 실패 연출은 짧게 간판이 꺼지는 정도이며 비난 문구·강한 점프스케어·조롱을 넣지 않는다.
- 지급 재화와 영구 보상은 MVP에 없고 결과 통계만 표시한다. 실패로 잃는 구매품도 없다.
- “무료 재도전”과 “대기실”을 즉시 선택할 수 있다. 실패 화면에 상점 링크를 넣지 않는다.
- 재도전은 현재 참가자 모두 준비하면 시작하며 이전 상품·주문·불안도·예약 사건을 초기화한다.
- 한 명만 준비하면 기다림·대기실 이동·혼자 연습 중 하나를 선택할 수 있고 자동 시작하지 않는다.

## 8. 중복 요청·이탈·진행 교착 방지
- 근무 ID와 주문 ID를 구분하고 서버가 활성 주문·상품·전달 거리·정전 여부를 확인한다.
- 주문 완료는 유효한 한 요청만 상태를 변경하며 같은 주문의 나머지 요청은 무효 응답을 받는다.
- 중복 요청으로 성공 수·결과 통계·향후 보상 지급 횟수가 늘어나면 결함으로 판정한다.
- 종료된 근무의 지연 요청은 새 근무에 적용하지 않는다. 재시작마다 새 근무 ID를 발급한다.
- 이탈 즉시 들고 있던 상품을 제거하고 표시판 연결·차단기 소유권을 해제한다.
- 이탈하면 근무·주문·정전 지연 타이머를 모두 최대 20초 멈추고 남은 사람에게 상태를 알린다.
- 남은 사람은 즉시 대기실 복귀 또는 혼자 마무리를 선택할 수 있다.
- 20초 동안 복귀하지 않으면 자동으로 혼자 마무리로 전환해 무기한 대기를 없앤다.
- 혼자 마무리에서는 차단기 화면에 도형 순서를 직접 제공하고 표시판 연결 요구를 해제한다.
- 진행 중 정전 입력은 초기화하되 정전 경과 시간과 이미 부과한 벌점은 보존한다.
- 혼자 마무리의 결과에는 ‘인원 조정’ 표지를 붙이고 정상 2인 협동 성과와 따로 집계한다.
- 남은 사람이 선택한 뒤에는 복귀자가 관전·대기만 하고 다음 근무부터 합류한다.
- 대기 중 원래 참가자가 돌아오면 양쪽 준비 확인 후 중단된 시점에서 2인 진행을 재개한다.
- 준비 확인도 최초 20초 제한 안에 끝내야 한다. 반복 이탈로 같은 근무의 대기 시간을 늘리지 않는다.
- 연결은 유지했지만 상대가 움직이지 않으면 도움말에서 혼자 마무리 전환을 요청할 수 있다.
- 요청은 상대에게 10초간 알리고 취소 응답이 없으면 적용한다. 해당 시간 동안 타이머는 유지한다.
- 상대가 취소하더라도 정전 45초 자동 복구와 근무 300초 종료는 계속 작동한다.
- 모두 이탈하면 근무를 종료하고 임시 상태를 폐기한다. 진행 저장·재접속 복원은 후속 범위다.
- 사례: 표시판 담당 이탈 → 타이머 정지 → 혼자 마무리 선택 → 차단기에 순서 표시 → 무료 종료.

## 9. 공포 강도·접근성·정보 식별
- 분위기는 빈 통로 벨·낮아진 조명·진열 변화로 만든다. 피·폭력·큰 비명은 필요하지 않다.
- 정전에도 이동 경로·출입구·상호작용 표지를 읽을 최소 조도를 유지한다.
- 화면 흔들림·섬광은 기본 사용하지 않는다. 소리는 분위기 보조이며 필수 단서가 아니다.
- 자막과 고정 도형 표시는 기본 켜짐이며 글자 확대 시 주문 이름을 잘라내지 않는다.
- 상품 포장 외형을 바꿔도 이름·도형·주문 카드·상호작용 윤곽은 동일하게 유지한다.
- 다른 플레이어의 장식이 표시판·상품 표지·차단기 버튼을 가리면 해당 장식은 채택하지 않는다.
- 무료 기본 외형도 같은 식별성과 시인성을 제공한다. 유료 외형에 단서 강조 기능을 넣지 않는다.

## 10. 무료 에셋과 권리 확인 절차
- MVP는 기본 Part·직접 작성한 도형/UI·직접 제작한 효과만 계획한다. 이번에는 반입하지 않는다.
- 외부 후보는 출처 URL·제작자·취득일·무료 여부·이용 조건 원문 위치를 기록한 뒤 검토한다.
- 무료 표시는 상업적 사용·수정·재배포 권한 확인을 대신하지 않는다. 불명확하면 채택을 보류한다.
- 캐릭터·로고·음원 등 제3자 권리와 출처 표기 의무도 별도로 확인하고 증빙을 보존한다.
- 모델 내부 스크립트·외부 모듈·불필요한 의존성은 메인이 검토하기 전 실행하지 않는다.
- 생성물이 필요하면 사용 도구의 당시 이용 조건과 입력 자료 권리를 확인한다. 유료 생성 API는 제외한다.
- 본 초안은 특정 에셋의 허가나 Roblox 정책 준수를 확인했다는 보고가 아니다.
- 실제 후보 채택 전 담당자가 Creator Store와 Assets 공식 문서를 확인하고 URL·확인일을 기록한다.

## 11. 선택적 수익화 후보와 검증
- 아래는 후속 연구 후보이며 첫 플레이 테스트에는 실제 상점·상품·구매 요청을 넣지 않는다.
- 후보 A: 앞치마 외형 묶음, 기준 가격 가설 49 Robux. 장비 능력과 실루엣 크기는 그대로다.
- 후보 B: 개인 명찰 테두리 묶음, 기준 가격 가설 29 Robux. 역할·주문 정보를 가리지 않는다.
- 후보 C: 대기실 개인 사물함 장식, 기준 가격 가설 79 Robux. 근무 동선과 공유 가게는 바꾸지 않는다.
- 모두 확정 외형을 미리 보는 방식이며 유료 랜덤·소모성 부활·시간 절약·진행 우위를 제외한다.
- 무료 기본 외형과 모든 밤·신호·재시작 기능만으로 정상 경험을 완결한다.
- 상점 진입은 대기실의 작은 꾸미기 버튼 하나로 한정하고 자동 팝업 노출은 0회로 한다.
- 공포 사건·근무 중·실패 결과에는 판매 노출이 없다. 결과에서 상점으로 자동 이동하지 않는다.
- 가격은 확정 요금이 아니다. 구매 없는 화면 시안으로 후보별 이해도·선호·거부 이유를 조사한다.
- 가격 민감도는 후보를 하나씩 보여 주고 낮음/기준/높음 가격 시안에 대한 선택 이유를 비교한다.
- 소규모 응답을 매출 예측으로 환산하지 않는다. 미성년 참여 시 보호자 동의와 무구매 조건을 마련한다.
- 후속 상품 방식·가격 표시·지역 가격 적용 가능성은 당시 공식 Passes/Regional pricing 문서로 확인한다.
- 공식 기능·수수료·지역별 실제 가격을 본 초안에서 단정하지 않는다. 실제 상품 생성·판매는 별도 승인이다.

## 12. 플레이테스트 계획과 통과 기준
- 아래는 예정된 검증이며 실행 기록이 아니다. 독립 검토도 아직 완료되지 않았다.
- 규칙 테스트: 동일 주문 동시 전달·이전 근무 요청·정전 중 전달·종료 직전 전달을 재현한다.
- 필수 판정: 주문은 정확히 1회만 완료되고 실패/성공/재시작 상태가 서로 중복되지 않아야 한다.
- 이탈 테스트: 표시판 연결 전후·차단기 입력 도중·결과·준비 화면에서 각각 이탈·복귀한다.
- 필수 판정: 타이머 정지와 재개가 규칙대로이며 혼자 마무리 또는 대기실로 반드시 빠져나온다.
- 일정 테스트: 일정 3개 × 초기 배치 6개를 점검하고 상품 누락·경로 차단·사건 중첩 교착은 0건이어야 한다.
- 무음 테스트: 처음 보는 2인 3쌍을 모집해 소리·음성 없이 두 번씩 플레이하게 하는 것을 초기 목표로 둔다.
- 관찰: 최초 주문까지 시간, 신호 발견, 정전 역할 분담, 오입력, 지원 복구, 이탈 선택을 기록한다.
- 사용성 가설 기준: 3쌍 중 2쌍 이상이 외부 설명 없이 첫 주문 60초 이내·협동 정전 45초 이내를 달성한다.
- 재미 가설 기준: 3쌍 중 2쌍 이상이 두 번째 밤의 행동 변화와 협동이 도움 된 순간을 구체적으로 설명한다.
- 실패 경험은 별도 유도 세션으로 확인하며 원인 이해·재시작 발견·불쾌한 순간을 질문한다.
- 모바일/키보드 혼합과 글자 확대에서 신호·버튼 가림 0건을 목표로 하고 장식 시안도 같은 기준을 적용한다.
- 기준 미달 시 주문 제한·안내·신호를 먼저 수정한다. 콘텐츠나 결제 기능 추가로 문제를 덮지 않는다.
- 소규모 통과는 출시나 수익 보장이 아니다. 개인 식별 정보 없이 관찰값과 발언 요약을 남긴다.
- 다음 단계: 독립 검토 이슈를 받은 뒤 수정안과 이슈별 수용·변경·보류 이유를 담당 파일에 작성한다.
- 첫 기획 결정: 원안의 강제 정전 성공 조건에 지원 복구를 추가해 이탈·무응답 교착을 제한했다.
- 첫 기획 결정: 초반 2인과 5분은 유지하고 조기 마감·인원 조정 종료를 추가해 불필요한 대기를 줄였다.
